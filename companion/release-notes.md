Ironkeep Companion 2.0.1

Discord authentication
The Windows app signs in with Discord. Uploads go to the guild selected for that session. The website login stays in the browser.

Forever SavedVariables
The WoW Forever card reports the account SavedVariables layout the app found. A selected folder that contains Ironkeep.lua under WTF\Account\<account>\SavedVariables is shown as found. A folder without that file stays explicit.

This build is the .NET 10 WPF application. Install IronkeepCompanionSetup.exe, or run IronkeepCompanion.exe directly. The checksums below are for those two files. This release does not replace the companion-latest tag.
